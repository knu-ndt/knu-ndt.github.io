01 / NDT

비파괴검사

NONDESTRUCTIVE TESTING

재료나 구조물을 손상시키지 않고 상태와 결함을 평가하는 기술입니다.

다양한 물리적 원리와 계측 방법을 바탕으로 재료와 구조물의 특성을 이해하고, 신뢰성 있는 검사와 진단 방법을 연구합니다.

  • 비파괴 계측
  • 결함 탐지·평가
  • 재료·구조물 진단

02 / SHM

구조건전성 모니터링

STRUCTURAL HEALTH MONITORING

구조물에서 얻는 다양한 정보를 바탕으로 상태와 변화를 파악하고 안전성을 평가하는 분야입니다.

센싱과 모니터링을 통해 구조물의 거동을 이해하고, 상태 평가와 합리적인 유지관리로 연결하는 방법을 연구합니다.

  • 센싱·모니터링
  • 구조물 상태 평가
  • 안전성·유지관리

03 / ML

데이터 기반 진단

MACHINE LEARNING & DATA ANALYSIS

계측 데이터에서 의미 있는 정보를 추출하여 상태 진단과 의사결정을 지원하는 분야입니다.

머신러닝과 데이터 분석을 활용해 복잡한 응답과 변화의 패턴을 해석하고, 재료와 구조물의 진단·예측·유지관리로 연결하는 방법을 연구합니다.

  • 데이터 해석
  • 상태 인식·예측
  • 지능형 유지관리
